# YouTube → транскрипция (Firefox)

Два дела на странице видео YouTube:

- **Субтитры**: скачать или скопировать в txt / srt / vtt / json, с таймкодами,
  автопереводом YouTube и именем файла «Канал - Название [язык]».
- **Озвучка**: вставляешь перевод с таймкодами, и он звучит поверх видео голосом
  TeraTTS. Каждая фраза начинается на своём таймкоде, оригинал на это время
  приглушается. Если фраза не влезает до следующей, она ускоряется без
  изменения тона.

Расширение открывается в боковой панели: значок на панели инструментов
открывает и закрывает её. Панель не закрывается, когда щёлкаешь по видео или
переключаешь вкладки, и сама подхватывает видео в активной вкладке.

## Что нужно для озвучки

**PDF-читалка 0.29 или новее** с голосами TeraTTS: «Настройки → Голоса и
модели». Голос синтезирует она: через неё работают скачанные голоса,
ускоритель TeraTTS и твой словарь ударений. Без читалки работают только
субтитры.

## Установка

### Насовсем (подписанная версия)

Firefox ставит насовсем только подписанные дополнения. Подписывает их
addons.mozilla.org (AMO) бесплатно и без публикации в каталоге (канал
unlisted), так же как подписана читалка. В репозитории это делает GitHub
Actions (workflow «Подпись и релиз»). Настраивается один раз:

1. **Ключи AMO.** Можно взять те же, что у читалки. Новые выдаёт
   https://addons.mozilla.org/developers/addon/api/key/ → Generate new
   credentials: *JWT issuer* и *JWT secret*.
2. **Секреты в этом репозитории.** Секреты читалки сюда не переходят: у
   каждого репозитория свои. Settings → Secrets and variables → Actions →
   New repository secret: `AMO_JWT_ISSUER` и `AMO_JWT_SECRET`.
3. **Подпись.** Actions → «Подпись и релиз» → Run workflow. Через несколько
   минут в Releases появится `youtube-transcript-<версия>.xpi`.
4. **Установка.** Удали временную версию в `about:debugging`, скачай `.xpi` из
   Releases и перетащи его в окно Firefox → «Добавить».

Новая версия: подними `version` в `manifest.json` и запушь. Workflow сам
подпишет её и выпустит релиз. Уже подписанную версию AMO второй раз не
принимает.

Автообновление работает, только если репозиторий публичный. Firefox скачивает
`updates.json` из последнего релиза без логина. Пока репозиторий приватный,
новую версию ставь вручную из Releases.

### Временно (для разработки)

1. Открой `about:debugging#/runtime/this-firefox`.
2. «Загрузить временное дополнение…» → выбери `manifest.json` из этой папки.
3. Обнови вкладки с YouTube (F5).

Временное дополнение пропадает после перезапуска Firefox.

## Как озвучить видео

1. Вкладка «Субтитры»: поставь галочку «Таймкоды», формат txt, нажми «Копировать».
2. Переведи текст, например в ChatGPT или Claude, с просьбой сохранить метки
   `[мм:сс]` в начале строк.
3. Вкладка «Озвучка»: вставь перевод, выбери голос и нажми «Озвучить». Панель
   можно закрыть: озвучка продолжится, а «Стоп» остановит её.

Понимает строки `[мм:сс] текст`, `[чч:мм:сс] текст`, `мм:сс текст`, а также
SRT и VTT. Строка без метки приклеивается к предыдущей фразе. Черновик
перевода запоминается отдельно для каждого видео.

Галочки:

- **Склеивать обрывки в предложения.** Автосубтитры режут речь на кусочки по
  2–3 секунды. Склейка (не длиннее 12 секунд) звучит естественнее.
- **Ставить видео на паузу, если фраза не готова.** Видео ждёт синтеза, и
  озвучка не отстаёт. Без галочки неготовая фраза пропускается.
