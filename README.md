# youtube-transcript

Расшифровки YouTube-видео: скачать субтитры, распознать речь, если субтитров
нет, и озвучить перевод поверх видео.

## Приложение для Windows (Python)

- `yt_gui.pyw` — окно. Запускается двойным кликом: вставляешь ссылки,
  выбираешь язык и формат, жмёшь «Скачать».
- `yt_transcript.py` — то же из консоли:
  `python yt_transcript.py ССЫЛКА -t -f srt`.
- `groq_asr.py` — распознавание речи у видео без субтитров через Groq Whisper
  (нужен бесплатный ключ с console.groq.com, поле «Ключ Groq» в окне).

Что умеет:

- форматы txt (по желанию с таймкодами), srt, vtt, json;
- автоперевод YouTube;
- имя файла «Канал - Название [язык]»;
- сам находит прокси VPN в настройках Windows, если YouTube напрямую
  недоступен.

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Настройки окна, вместе с ключом Groq, хранятся в `settings.json` рядом со
скриптом. Этот файл в репозиторий не попадает.

## Расширение для Firefox

Папка [`firefox-extension`](firefox-extension/README.md):

- субтитры прямо со страницы видео;
- озвучка вставленного перевода голосом TeraTTS через
  [PDF-читалку](https://github.com/chadgpttop666/pdf) 0.29+: оригинал на время
  фраз приглушается, длинные фразы ускоряются без изменения тона.
